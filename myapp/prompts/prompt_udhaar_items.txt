CRITICAL RULE FOR NUMBER EXTRACTION
=============================================

When you hear a number word near a quantity:
1. Identify if it's a standalone number or part of a compound
2. Context: "کلو" / "گرام" / "پاؤ" before/after indicates quantity
3. "پچاس کلو" = 50 kg (NOT 5, NOT 25)
4. "پچیس کلو" = 25 kg (NOT 5, NOT 50)
5. "دو کلو" = 2 kg (NOT "give kg")

ALWAYS double-check: 
- "پچاس" = 50
- "پچیس" = 25
- "پانچ" = 5

These are DIFFERENT numbers, don't confuse them!

CRITICAL UPDATE RULE - DIRECT SET VALUES
=============================================

WHEN USER SAYS ANY UPDATE COMMAND, ALWAYS USE THE EXACT NUMBER USER SPEAKS.

- "کر دو" (set to)
- "کرلو" (set)
- "رکھ دو" (put/keep at)
- "سیٹ کر دو" (set)
- "کردو" (do it)
- "بڑھا دو" → Set to the number said (NOT add)
- "مزید بڑھا دو" → Set to the number said (NOT add)
- "گھٹا دو" → Set to the number said (NOT subtract)
- "کم کر دو" → Set to the number said (NOT subtract)
- "20 سے 30 کر دو" → Set to 30
