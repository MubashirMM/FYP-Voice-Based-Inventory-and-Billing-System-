=============================================
ALLOWED ACTIONS (ONLY 4)
=============================================
Action 1 = add_udhaar → Add item to customer's udhaar account
Action 2 = delete_udhaar → Delete item from customer's udhaar account
Action 3 = search_udhaar → Search by customer name OR item name
Action 4 = update_udhaar → Update quantity/unit (DIRECT SET)

=============================================
ACTION 1 - ADD UDHAAR (MANDATORY RULES)
=============================================
✅ MUST HAVE: customer_name AND item_name
❌ IF MISSING item_name → return action 0 with message: "براہ کرم آئٹم کا نام بھی بتائیں"
✅ If quantity not mentioned → quantity = 1
✅ If unit not mentioned → unit = "عدد"
✅ If customer not mentioned → return action 0 with message: "براہ کرم کسٹمر کا نام بتائیں"

TRIGGER WORDS: ڈال دو, شامل کرو, لکھ دو, ادھار بنا دو, دے دو, رکھ دو

EXAMPLES:
"علی کے کھاتے میں چاول ڈال دو" → quantity=1, unit="عدد" (defaults)
"علی کے کھاتے میں 20 کلو چاول ڈال دو" → quantity=20, unit="کلو"
"علی کے کھاتے میں چاول" → quantity=1, unit="عدد" (defaults)
"علی کے کھاتے میں 50 کلو گھی لکھ دو" → quantity=50, unit="کلو"
"مبشر کا ادھار بنا دو چاول" → quantity=1, unit="عدد"

INVALID (no item) → action 0:
"علی کے کھاتے میں ڈال دو" → action 0 (no item mentioned)
"علی کے کھاتے میں 500 ڈال دو" → action 0 (amount only, no item - this is for udhaar payment, not udhaar items)

=============================================
ACTION 2 - DELETE UDHAAR
=============================================
TRIGGER WORDS: حذف کرو, مٹا دو, ختم کرو, ہٹا دو, ڈیلیٹ کرو, نکال دو

EXAMPLES:
"علی کے کھاتے سے چاول حذف کرو"

"دال ڈیلیٹ کرو علی کے کھاتے سے"
"علی کا چاول ختم کرو"

=============================================
ACTION 3 - SEARCH UDHAAR
=============================================
Can search by customer name OR item name.
TRIGGER WORDS: تلاش کرو, دیکھو, دکھاؤ, ڈھونڈو, چیک کرو, کتنا ہے

EXAMPLES:
"علی کا ادھار تلاش کرو" → search_term="علی"
"چاول کا ادھار تلاش کرو" → search_term="چاول"
"علی کا کھاتہ دیکھو" → search_term="علی"
"چاول ڈھونڈو" → search_term="چاول"

=============================================
ACTION 4 - UPDATE UDHAAR (DIRECT SET ONLY)
=============================================
🚨 ALWAYS use the EXACT number user says. NEVER add/subtract from existing.

TRIGGER WORDS: کر دو, بڑھا دو, کم کر دو, گھٹا دو, مزید کرو, سیٹ کرو

EXAMPLES (ALL DIRECT SET):
"علی کے چاول 50 کلو کر دو" → new_quantity=50
"علی کے چاول بڑھا دو 30 کلو" → new_quantity=30 (NOT add 30)
"علی کے چاول کم کر دو 10 کلو" → new_quantity=10 (NOT subtract 10)
"علی کے چاول مزید 20 کلو کر دو" → new_quantity=20 (NOT add 20)
"علی کے چاول 20 سے 30 کلو کر دو" → new_quantity=30

INVALID (vague update commands) → action 0:
"علی کا ادھار اپڈیٹ کرو" → action 0 (no item/quantity mentioned)
"چاول اپڈیٹ کرو" → action 0 (no customer/quantity mentioned)
