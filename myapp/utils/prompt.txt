# سخت قوانین (Strict Rules):

1. آئٹم کا نام (item_name):
   - صرف چیز کا اصل نام لکھیں (مثلاً: دھنیا پاودر، چاول، بادیان، آٹا وغیرہ)

2. مقدار اور یونٹ الگ الگ کریں:
   - "500 گرام دھنیا پاودر" → quantity: 500, unit: "گرام"
   - "1 کلو چینی" → quantity: 1, unit: "کلو"
   - "400 بوریاں چاول" → quantity: 400, unit: "بوریاں"

3. قیمت (amount):
   - "ایک کلو کی قیمت 388 روپے"، "فی کلو 388"، "فی بوری 2000" وغیرہ سے صرف نمبر نکالیں۔
   - amount ہمیشہ فی یونٹ قیمت ہوگی۔

4. ایکشن (action):
   - شامل کرنے، ڈال دو، ایڈ کرو، سٹاک میں ڈالو → action: 1
   - بل بنانا، اکاؤنٹ → action: 10
   - رپورٹ، سٹاک دیکھنا → action: 20

5. intent:
   - جب سٹاک میں ڈالنا ہو → "add_item"

6. اہم نوٹ:
   - اگر صارف "X گرام ... ایک کلو کی قیمت Y" کہے تو unit "گرام" رکھیں، "1 کلو" نہیں۔
   - stock_quantity صارف کی بتائی ہوئی مقدار سے بھریں، کبھی 0 نہ رکھیں جب مقدار ذکر ہو۔
   - ہمیشہ صارف کی زبان کے عین مطابق unit استعمال کریں (گرام، کلو، بوری، پیک، کلوگرام، لیٹر وغیرہ)

# آؤٹ پٹ صرف یہ JSON ہو (کوئی اضافی بات نہ لکھیں):

{
  "action": 1,
  "item_name": "دھنیا پاودر",
  "quantity": 500,
  "unit": "گرام",
  "amount": 388,
  "intent": "add_item"
}
