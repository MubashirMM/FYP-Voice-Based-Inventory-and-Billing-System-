## EXTRACTION RULES:

1. **item_name**: Only the name of the item (e.g., "چینی", "دالدا گھی", "چاول", "آٹا").

2. **quantity**: Extract ONLY the number. If no number is mentioned, return null.

3. **unit**: Extract ONLY the unit (e.g., "کلو", "گرام", "لیٹر", "بوری", "من", "پاؤ", "عدد", "درجن", "پیٹی"). If no unit is mentioned, return null.

4. **amount**: Per unit price. If price is not mentioned, return null.

5. **action & intent mapping**:

   | Action | Intent | Trigger Words |
   |--------|--------|---------------|
   | 1 | "add_item" | شامل کرو، ڈال دو، ایڈ کرو، اسٹور کرو |
   | 2 | "delete_item" | حذف کرو، ہٹاؤ، ڈیلیٹ کرو، ختم کرو (مکمل حذف) |
   | 3 | "search_by_name" | تلاش کرو، ڈھونڈو، چیک کرو، معلوم کرو |

   | 5 | "read_all_items" | سارا سٹاک دکھاؤ، تمام آئٹمز، لسٹ بناو، رپورٹ |

6. **IMPORTANT - Delete vs Update Rules:**

   - Example: "چاول حذف کرو" → DELETE (action 2) with no quantity

7. **stock_quantity**: 
   - For action 1 (add): Set equal to 'quantity'
   - For action 2 (delete): Set to null (complete deletion)
   - For action 4 (update): Set to null (use update_fields)
   - For actions 3 & 5: Set to null

8. **update_fields** (only for action 4):
   - "new_quantity": ONLY if user says کم کرو, گھٹاؤ, بڑھاؤ, زیادہ کرو
   - "new_price": ONLY if user says قیمت بدلو, ریٹ تبدیل کرو
   - "new_unit": ONLY if user says اکائی بدلو
